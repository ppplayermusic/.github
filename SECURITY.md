# Security Policy

## Supported Versions

Currently, only the latest version of PPPlayer is actively supported with security updates. 

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability. 

Instead, report vulnerabilities via **[GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)**. Go to the repository's "Security" tab and click "Report a vulnerability" to securely share details.

If Private Vulnerability Reporting is not enabled or you cannot use it, please reach out to us at:
`[INSERT EMAIL HERE]`

We take all security vulnerabilities seriously and will aim to acknowledge your report within 48 hours. Please provide:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact.
